# 합성 버튼과 다른 등급이 합쳐짐

- 날짜와 시간: 2026-10-04 15:55:15
- 본 현상: 어떤 등급의 합성 버튼을 눌러도 그 등급이 아닌 유닛이 합성에 들어갔다.
- 재현 순서: 같은 시각에 나온 유닛처럼 id가 겹친 일반과 레어를 두고, 레어 카드의 합성을 누른다.
- 확인한 파일: `Client/src/game/engine.js`, `Client/src/components/GameScreen.vue`
- 원인: 유닛 id가 `Date.now()`라 겹칠 수 있고, 합성은 그 id로 처음 찾은 유닛의 등급에서 앞 3마리를 뺐다.
- 원본 변경 여부: `maple_unlucky_defense (51).html`은 수정하지 않았다.
- 결과: 겹친 id만 넘기면 합성하지 않는다. 클릭한 레어 객체는 레어 3마리만 고급으로 바꾸고 일반 3마리는 남긴다. `npm run check`로 확인했다.
