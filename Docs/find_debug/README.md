# find_debug

재현된 문제와 그 원인을 찾는 기록을 둔다. 현상을 확인하기 전에 원인을 단정하지 않는다.

새 기록 파일 이름은 `YYYYMMDD-HHMMSS-짧은제목.md`로 한다.

```
# 제목

- 날짜와 시간:
- 본 현상:
- 재현 순서:
- 확인한 파일:
- 원인:
- 원본 변경 여부:
- 결과:
```

## 기록

- `20261004-155252-화면비율.md` — 화면이 가로 전체를 채우지 않던 문제. 컨테이너 폭 제한과 고정 크기가 원인이었다.
- `20261004-155410-배속소환.md` — 배속 변경이 남은 소환을 끊던 문제. 간격을 지우기만 한 것이 원인이었다.
- `20261004-155515-합성등급.md` — 합성이 클릭한 등급이 아닌 유닛을 넣던 문제. 겹친 id로 찾던 것이 원인이었다.
