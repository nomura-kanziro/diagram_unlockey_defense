# find_debug

재현된 문제와 그 원인을 찾는 기록을 둔다. 현상을 확인하기 전에 원인을 단정하지 않는다.

새 기록 파일 이름은 `YYYYMMDD-HHMMSS-짧은제목.md`로 한다.

```
# 제목

- 날짜와 시간:
- 본 현상:
- 재현 순서:
- 확인한 파일:
- 원인:
- 원본 변경 여부:
- 결과:
```
