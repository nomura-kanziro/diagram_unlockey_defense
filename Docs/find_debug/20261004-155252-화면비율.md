# 화면이 가로 전체를 채우지 않음

- 날짜와 시간: 2026-10-04 15:52:52
- 본 현상: 게임 화면 옆에 빈 공간이 남고, 창 비율이 바뀌어도 전장 크기가 따라가지 않았다.
- 재현 순서: Vue 클라이언트를 연 뒤 넓은 창과 세로로 긴 창에서 전장과 사이드바 위치를 본다.
- 확인한 파일: `Client/src/styles/game.css`, `Client/src/game/engine.js`
- 원인: 컨테이너 `max-width: 1200px`와 고정된 사이드바·캔버스 크기 때문에 남은 가로를 쓰지 못했다. 골드 숫자는 캔버스 내부 좌표를 그대로 썼다.
- 원본 변경 여부: `maple_unlucky_defense (51).html`은 수정하지 않았다.
- 결과: 컨테이너가 창 너비와 같다. 전장은 정사각형이다. 가로 1400에서는 사이드바가 오른쪽, 세로 420×900에서는 사이드바가 전장 아래다. Chrome headless로 두 크기를 확인했다.
