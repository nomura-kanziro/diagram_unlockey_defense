# 배속을 바꾸면 남은 적이 나오지 않음

- 날짜와 시간: 2026-10-04 15:54:10
- 본 현상: 적이 나오는 중인 라운드에서 배속을 바꾸면 그 라운드의 적이 더 나오지 않고, 다음 라운드가 되어야 나왔다.
- 재현 순서: 일반 라운드가 시작된 뒤 배속 버튼을 누른다.
- 확인한 파일: `Client/src/game/engine.js`
- 원인: 배속 변경이 소환 간격만 지우고 다시 걸지 않았다. 나온 수도 그 간격 함수 안에만 있어서 이어서 셀 수 없었다.
- 원본 변경 여부: `maple_unlucky_defense (51).html`은 수정하지 않았다.
- 결과: 나온 수를 유지한 채 간격을 다시 건다. `npm run check`에서 1배속 1530ms로 1마리, 2배속 765ms로 같은 라운드에 1마리를 더 소환하는 것을 확인했다.
