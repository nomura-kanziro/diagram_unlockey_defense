# 화면 가로, 배속 소환, 합성 등급

- 날짜와 시간: 2026-10-04 06:33:33
- 본 현상: Vue 화면이 가로 전체를 채우지 않고 비율에 맞춰 줄거나 커지지 않았다. 라운드 중에 배속을 바꾸면 남은 적이 나오지 않고 다음 라운드에 나왔다. 합성 버튼을 누르면 그 카드의 등급이 아닌 다른 등급이 합쳐졌다.
- 재현 순서: `Client`에서 게임을 시작한다. 넓은 창과 세로로 긴 창에서 좌우 빈칸과 전장 크기를 본다. 다음 라운드 직후 2배를 누르고 적 수가 같은 라운드에서 늘어나는지 본다. 일반 3마리와 레어 3마리가 있을 때 레어 카드의 합성을 누른다.
- 확인한 파일: `Client/src/styles/game.css`, `Client/src/game/engine.js`, `Client/src/components/GameScreen.vue`, `Client/scripts/check-rules.mjs`. 원본 HTML의 `setGameSpeed`는 소환 타이머를 지우기만 하고, 유닛 id는 `Date.now()`라 서로 겹칠 수 있다.
- 원인: `.container`의 `max-width: 1200px`와 캔버스 CSS 크기 700px가 가로를 고정했다. `setGameSpeed`가 `spawnInterval`만 지우고, 소환한 마리 수는 `nextRound` 지역 변수라 다시 시작할 수 없었다. 합성은 클릭한 객체가 아니라 id로 첫 유닛을 찾아, 같은 id의 다른 등급을 집었다.
- 원본 변경 여부: `maple_unlucky_defense (51).html`은 수정하지 않았다.
- 결과: Vue 화면은 가로 전체를 쓰고, 원형 전장은 남은 칸에 맞춰 정사각형으로 변한다. 세로가 더 길면 사이드바는 전장 아래로 내려간다. 배속을 바꾸면 이미 나온 적을 유지한 채 남은 소환이 새 간격으로 이어진다. 합성은 클릭한 유닛의 등급만 3마리 소모한다. `npm run check`와 `npm run build`를 통과했다. Chrome에서 1600×900, 1100×700, 390×844를 확인했다.
