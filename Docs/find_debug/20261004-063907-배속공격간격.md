# 배속에 공격 간격이 따라가지 않음

- 날짜와 시간: 2026-10-04 06:39:07
- 본 현상: 배속을 올려도 소환 유닛의 공격 간격은 1배 그대로였다. 배속을 낮춰도 공격이 느려지지 않았다.
- 재현 순서: 게임을 시작하고 유닛 카드의 공격속도를 본다. 2배, 4배, 1배를 차례로 누르고 숫자와 실제 공격 시점을 본다.
- 확인한 파일: `Client/src/game/engine.js`의 `getAttackInterval`, `performAttacks`. 원본 HTML도 공격 간격에 배속을 나누지 않는다.
- 원인: 공격 간격이 `max(200, 1000 - (레벨-1) * 60)`으로만 계산되고 `gameSpeed`를 쓰지 않았다. 배속은 적 이동, 라운드 시간, 적 소환에만 들어가 있었다.
- 원본 변경 여부: `maple_unlucky_defense (51).html`은 수정하지 않았다.
- 결과: Vue 클라이언트의 공격 간격은 그 값을 배속으로 나눈다. 1레벨은 1초에 1.00초, 2배에 0.50초, 4배에 0.25초, 6배에 0.16초다. 배속을 내리면 간격이 다시 길어진다. 카드 숫자도 같이 바뀐다. `npm run check`와 `npm run build`를 통과했다. Chrome에서 1배 350ms 동안은 공격이 없고, 4배로 바꾸면 같은 대기 중에 공격하며, 다시 1배로 낮추면 300ms 동안 추가 공격이 없음을 확인했다.
