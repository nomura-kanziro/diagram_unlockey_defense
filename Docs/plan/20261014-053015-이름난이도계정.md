# 도형 운빨 디펜스, 난이도, 계정

- 확정 명령: 게임 이름을 도형 운빨 디펜스로 바꾸고 시작 화면을 게임답게 다듬는다. 기존 200레벨을 보통으로 두고, 쉬움 150레벨은 보통보다 1.5배 쉽게, 어려움 250레벨은 1.5배 어렵게, 불가능 300레벨은 2배 어렵게 만든다. 보통 클리어는 어려움을, 어려움 클리어는 불가능을 연다. 어려움은 6번째 보스부터, 불가능은 4번째 보스부터 쉴드가 있고 쉴드는 보스 일반 체력의 8분의 1이다. 불가능은 쉴드가 깨진 뒤 5초면 쉴드가 다시 찬다. 아이디와 비밀번호로 가입하고 로그인하면 SQLite에 클리어가 남는다. 불가능 클리어 계정은 아이디 뒤에 명예의 전당이 붙는다.
