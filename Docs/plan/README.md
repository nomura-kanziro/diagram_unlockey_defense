# plan

사용자가 제시한 확정 명령에 대한 진행 계획만 둔다. 작업 전에 작성한다. 이미 끝난 작업의 사후 계획, 사용자가 확정하지 않은 제안은 넣지 않는다.

계획 파일 이름은 `YYYYMMDD-HHMMSS-짧은제목.md`로 한다.

```
# 제목

- 확정 명령:
- 날짜와 시간:
- 읽을 문서:
- 바꿀 범위:
- 유지할 원본:
- 순서:
- 끝낸 뒤 갱신할 문서:
```

## 현재 계획

진행 중인 작업 전 계획은 없다. 2026-10-04의 에이전트 폴더와 Docs 작성은 확정 명령으로 바로 실행한 작업이라 이 폴더에 계획 파일을 만들지 않았다.
