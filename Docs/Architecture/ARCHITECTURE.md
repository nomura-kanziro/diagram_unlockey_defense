# Architecture

이 문서는 2026-10-04에 저장소에 있던 프로토타입의 구성이다. 게임 원본 `maple_unlucky_defense (51).html`을 기준으로 한다. 서버와 데이터베이스는 없다.

## 구성

실행 단위는 HTML 파일 하나다. 브라우저가 그 파일을 열면 화면, 스타일, 게임 상태가 함께 올라온다. 빌드 단계와 패키지 관리자는 없다.

| 구성 요소 | 위치 | 하는 일 |
|---|---|---|
| 시작 화면 | 같은 HTML의 `#start-screen` | 게임 시작, 설명 모달 |
| 상단 상태 | `#game-screen .top-ui` | 골드, 레벨, 시간, 적 수, 다음 라운드, 배속 |
| 전장 | `#game-canvas` 700×700 | 원형 맵, 유닛, 적, 공격선 |
| 조작 패널 | `.sidebar` | 소환, 강화, 승천, 유닛 목록, 확률, 적 체력, 로그 |
| 게임 상태 | 같은 파일의 `<script>` | 골드, 레벨, 유닛, 적, 타이머, 방어력, 버프 |
| 문서와 규칙 | `Docs`, `.agents`, 각 에이전트 폴더 | 게임 실행과 분리된 작업 규칙 |

## 동작 원리

브라우저의 `requestAnimationFrame`이 `gameLoop`를 반복한다. 한 프레임은 적 이동, 유닛 공격, 캔버스 그리기, 화면 숫자 갱신, 타이머 감소 순서다.

좌표계는 캔버스 중심 `(350, 350)`이다.

- 바깥 원 반지름 280은 적 궤도와 12시 소환 포탈이다.
- 안쪽 원 반지름 140은 유닛 배치 영역이다.
- 유닛은 안쪽 원 안 무작위 좌표에 놓이고, 가장 가까운 적을 고른다.
- 일반 적은 포탈 근처에서 나와 바깥 원 위를 돈다. 보스와 데스매치 적은 궤도 위 무작위 각도에서 나온다.
- 적이 기지를 공격하는 계산은 없다. 패배는 필드 위 적이 100마리 이상이거나, 보스·데스매치 제한 시간이 끝났는데 적이 남은 경우다.
- 승리는 `currentLevel`이 200을 넘는 경우다.

등급 수치, 확률, 강화, 합성, 승천, 히든 조합, 라운드 배율은 루트 `README.md`에 정리되어 있다. 화면의 게임 설명 모달과 스크립트 수치가 다른 항목도 그 파일에 적혀 있다.

## 구성 요소 관계

```
플레이어 입력
  ├─ 소환 / 강화 / 버프 / 승천 / 합성 / 판매 / 다음 라운드 / 배속
  └─ 골드와 유닛 배열을 바꿈
        │
        ▼
gameLoop
  ├─ enemies : 궤도 이동, 사망 시 골드, 100마리 패배
  ├─ units   : 공격 간격마다 최근접 적과 범위 피해
  └─ 타이머  : 대기, 일반 라운드, 보스, 데스매치
        │
        ▼
canvas + 사이드바 표시
```

데이터는 모두 페이지 메모리의 변수다. 저장, 계정, 네트워크 요청은 없다. 게임을 닫으면 진행은 사라진다.

## Vue 클라이언트

같은 게임을 루트 `Client`에서 Vue 3로 다시 구성했다. 원본 HTML은 수정하지 않았다. Git 브랜치 `Client`에 둔다.

| 구성 | 위치 |
|---|---|
| 화면 | `StartScreen.vue`, `GameScreen.vue`, `ExplanationModal.vue` |
| 상태와 전투 | `src/game/engine.js`의 reactive 상태와 `requestAnimationFrame` |
| 등급 수치 | `src/game/constants.js` |
| 스타일 | `src/styles/game.css` |

브라우저가 Vite 개발 서버 또는 `npm run build` 결과를 연다. 저장, 계정, 서버 API는 여전히 없다. 게임을 닫으면 진행은 사라진다.

`.game-screen`은 세로 방향 flex다. 화면은 브라우저 가로 전체를 쓴다. 원형 전장은 남은 칸의 짧은 변에 맞춰 정사각형으로 커지거나 줄어든다. 세로가 더 긴 화면에서는 사이드바가 전장 아래로 내려간다. 캔버스 비트맵은 700×700이다. 일반 라운드에서 배속을 바꾸면 남은 적 소환은 이어서 나온다. 합성은 클릭한 유닛의 등급만 합친다.

## 아직 없는 계층

| 계층 | 상태 |
|---|---|
| Server | 프로세스, API, 배포 서버가 없다. |
| database | 접속 정보, 스키마, 저장 데이터가 없다. |

서버와 데이터베이스 브랜치의 구현 지시는 아직 없다.
