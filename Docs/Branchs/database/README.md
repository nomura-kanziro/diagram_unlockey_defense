# database

데이터베이스 작업 브랜치의 문서 자리다. 폴더 이름은 사용자가 지정한 `database`다.

Git 브랜치 `database`는 아직 없다. 사용자 지시 없이 만들지 않는다.

계정 저장은 SQLite 파일 `Server/data/accounts.sqlite`다. 서버 프로세스가 그 파일을 직접 열고, 별도 데이터베이스 서버는 없다. 파일은 Git에 넣지 않는다.

`users`에는 아이디, 비밀번호 해시, 솔트, 쉬움, 보통, 어려움, 불가능 클리어 여부가 있다. `sessions`에는 로그인 토큰과 아이디가 있다. 보통 클리어는 어려움 해금, 어려움 클리어는 불가능 해금이다. 불가능 클리어는 아이디 뒤에 명예의 전당을 붙인다.
