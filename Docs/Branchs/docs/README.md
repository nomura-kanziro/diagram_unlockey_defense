# docs

문서 작업 브랜치의 문서 자리다. 폴더 이름과 Git 브랜치 이름은 사용자가 지정한 `docs`다.

Git 브랜치 `docs`가 있다. 문서만 바꾸는 커밋은 이 브랜치에 둔다.

클라이언트, 서버, 데이터베이스의 기능을 바꾸는 커밋은 각 담당 브랜치에 둔다. 그 기능 커밋이 자기 설명을 문서에 남기는 것은 그 기능 커밋에 포함된다. 개발 중 병합 대상은 `Devolop`이고, `master`는 완성 뒤에만 병합한다. 병합은 그 차례의 담당 브랜치 커밋이 모두 끝난 뒤에 한 번에 한다. `docs`의 기존 커밋은 `Client` 역사에 이미 들어 있다.
