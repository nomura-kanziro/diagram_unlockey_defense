# 커밋 템플릿

`records` 폴더에 아래 항목을 채워 저장한다. 일련번호는 0001부터 커밋마다 1씩 올린다. 날짜와 시간은 로컬 시각이며 초까지 적는다.

```
# 커밋 기록

- 커밋 일련번호: 0000
- 날짜와 시간: YYYY-MM-DD HH:mm:ss
- 커밋 작업 내용: feat : 한글 본문
- 상세 내용:
  - 바꾼 범위
  - 유지한 원본
  - 확인한 문서
- 결과:
  - 브랜치:
  - 해시:
  - 상태:
```

해시는 커밋 직후 `git log -1 --format=%H` 값이다. 커밋 전에는 `커밋 후 기입`이라고 적고, 커밋 뒤에 실제 해시로 바꾼 뒤 그 갱신도 다음 기록에 남긴다.
