# Branchs

브랜치 역할과 커밋 기록을 적는 폴더다. 문서 폴더 이름과 Git 브랜치 이름을 구분한다.

| 폴더 | 역할 | Git 브랜치 |
|---|---|---|
| `Master` | 완성 뒤의 메인과 배포 | `master` |
| `Devolop` | 개발 중 병합과 테스트 | `Devolop` |
| `Client` | 클라이언트 기능 | `Client` |
| `Server` | 서버 역할 설명 | 없음 |
| `database` | 데이터베이스 역할 설명 | 없음 |
| `docs` | 문서만 바꾸는 커밋 | `docs` |
| `commits` | 커밋 문장, 템플릿, 기록 | 없음 |

개발 중 병합은 관련된 브랜치의 커밋을 모두 끝낸 뒤에 `Devolop`으로 한 번에 한다. `master`는 완성이 끝난 뒤에만 병합한다. `develop`이라는 브랜치는 만들지 않는다.
