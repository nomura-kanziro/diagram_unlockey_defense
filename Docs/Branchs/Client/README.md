# Client

클라이언트 작업 브랜치의 문서 자리다.

Git 브랜치 `Client`가 있다. 클라이언트 기능 커밋은 이 브랜치에 둔다.

플레이하는 클라이언트는 루트 `Client`다. Vue 3와 Vite로 만들었고, 규칙과 전투는 `maple_unlucky_defense (51).html`과 같다. 화면은 브라우저 가로 전체를 쓰고, 원형 전장은 남은 칸 비율에 맞춰 정사각형이다. 일반 라운드에서 배속을 바꿔도 남은 적 소환은 이어진다. 합성은 같은 모양, 같은 등급 3마리만 합친다. 소환 유닛의 공격 간격은 게임 배속을 따른다. 유닛 강화의 현재 가격은 버튼 오른쪽 판에 나온다. 1단위는 3번마다 1원, 5단위는 매번 3원 오른다. 소환 유닛은 원형, 삼각형, 사각형이다. 종말과 뫼비우스는 원형만이다. 뫼비우스 공격은 태초, 종말과 같은 무한 스플래시다. 오른쪽 사이드바에 유닛 판매 및 합성 칸이 있다. 고른 모양과 등급만 전부 팔거나 전부 합친다. 오른쪽 로그 아래 컬렉션은 한 판에 항목마다 한 번만 달성된다. 소환된 유닛 최대는 100마리다. 그 HTML은 원본으로 남아 있으며 수정하지 않았다.

실행은 `Client`에서 `npm install` 뒤 `npm run dev`다. 주소는 `http://localhost:5173/` 이다.

전투 상태, 소환, 강화, 합성, 승천, 라운드는 `Client/src/game/engine.js`에 있다. 서버로 상태를 보내지 않는다.
