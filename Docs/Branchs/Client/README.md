# Client

클라이언트 작업 브랜치의 문서 자리다.

Git 브랜치 `Client`는 아직 없다. 사용자 지시 없이 만들지 않는다.

플레이하는 클라이언트는 루트 `Client`다. Vue 3와 Vite로 만들었고, 전투 규칙은 `maple_unlucky_defense (51).html`과 같다. 화면은 브라우저 가로 전체를 쓰고 전장 크기가 비율에 맞춰 변한다. 배속을 바꿔도 이번 라운드의 남은 소환이 이어지고, 소환 유닛의 공격도 그 배속만큼 빨라지거나 느려진다. 합성은 클릭한 등급만 합친다. 그 HTML은 원본으로 남아 있으며 수정하지 않았다.

실행은 `Client`에서 `npm install` 뒤 `npm run dev`다. 주소는 `http://localhost:5173/` 이다.

전투 상태, 소환, 강화, 합성, 승천, 라운드는 `Client/src/game/engine.js`에 있다. 서버로 상태를 보내지 않는다.
