# Master

메인 브랜치이자 배포 브랜치의 문서 자리다.

현재 Git 브랜치 이름은 `master`다. 문서 폴더 이름은 사용자가 지정한 `Master`다. 두 이름은 같은 역할을 가리킨다. 브랜치 이름은 사용자 지시 없이 바꾸지 않는다.

이 브랜치에 올라온 변경은 배포 후보로 본다. 배포 점검 항목은 `Docs/web_management`에 있고, 커밋 기록은 `Docs/Branchs/commits/records`에 있다.

2026-10-14 기준, 이 브랜치는 개발 중 병합 대상이 아니다. 완성이 끝난 뒤에만 병합한다. 같은 날 `Client`를 여기로 병합했던 커밋은 브랜치 끝에서 뺐다. 이 브랜치는 `adbef34f08df944c22dc789d609d16f93982534e`를 가리킨다.

플레이용 클라이언트는 Git 브랜치 `Client`의 루트 `Client`다. 개발 중 통합은 `Devolop`에 둔다. 문서만 바꾸는 커밋은 Git 브랜치 `docs`에 둔다. 원본 HTML도 남아 있다. 서버 배포물은 없다. `master`에는 클라이언트 기능 커밋을 직접 넣지 않는다.
