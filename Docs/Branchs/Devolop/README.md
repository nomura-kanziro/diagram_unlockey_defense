# Devolop

개발 결과를 모으는 브랜치의 문서 자리다. 역할은 병합 전용과 테스트다. 폴더 철자는 사용자가 지정한 `Devolop`이다.

Git 브랜치 `Devolop`은 개발 모드의 병합 대상이다. 철자는 `Devolop`이다. `develop`으로 만들지 않는다.

지금은 개발 중이다. 담당 브랜치의 결과는 여기로만 병합한다. `master`로는 게임이 완성된 뒤에만 병합한다. 2026-10-14에 `master`로 넣었던 병합은 취소했다.

테스트 기록은 `Docs/trainings`, 검증 기록은 `Docs/vaildates`에 남긴다. 병합 커밋도 `Docs/Branchs/commits/records`에 남긴다.
