# Docs

작업 전에 관련 문서를 읽고, 작업 뒤에 바뀐 내용을 갱신한다. 규칙의 원본은 `.agents/RULES.md`다.

| 폴더 | 역할 |
|---|---|
| `Architecture` | 구성, 동작 원리, 구성 요소의 관계 |
| `Branchs` | 브랜치별 작업 범위. 커밋 가이드와 기록은 `Branchs/commits` |
| `Build-up` | 단계적으로 쌓는 준비와 진행 |
| `Changelog` | 버전별 변경을 시간순으로 기록 |
| `find_debug` | 디버그 기록 |
| `guidance` | 규칙, 도구, 문서 사용법 |
| `plan` | 사용자가 확정한 명령의 작업 전 계획 |
| `repeater` | 기능 사이에 반복되는 핵심 |
| `structure` | 저장소 폴더와 파일 구조 |
| `trainings` | 테스트 기록 |
| `vaildates` | 검증 기록 |
| `web_management` | 배포 전 점검과 배포 상태 |

게임 설명은 저장소 루트 `README.md`에 있다. 이 폴더는 그 파일을 대체하지 않는다.
