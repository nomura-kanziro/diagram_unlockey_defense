# .Vscode

VS Code용 에이전트 폴더다. Windows에서는 이 폴더가 `.vscode`와 같은 경로다.

이 폴더는 편집기 설정 폴더와 경로가 같다. `settings.json`, `launch.json`, `tasks.json`, `extensions.json`은 사용자 지시 없이 만들지 않는다. 지금 있는 파일은 에이전트 규칙과 이 설명뿐이다.

VS Code Copilot이 저장소 루트에서 읽는 지침은 `AGENTS.md`다. 이 폴더의 작업 규칙은 `RULES.md`다. 통합 원본은 `.agents/RULES.md`다.
