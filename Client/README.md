# Client

메이플 운빨 디펜스의 Vue 3 클라이언트다. 화면, 문구, 등급, 소환, 강화, 합성, 승천, 전투 루프는 `maple_unlucky_defense (51).html`과 같다. 그 HTML 파일은 원본으로 남겨 두었고 이 폴더가 바꾸지 않는다.

## 실행

저장소 루트에서 `npm install`과 `npm run dev`를 실행해도 이 폴더의 설치와 개발 서버로 이어진다. `Client` 안에서 직접 실행해도 같다.

```
npm install
npm run dev
```

브라우저에서 `http://localhost:5173/` 을 연다.

규칙 수치 확인은 `npm run check`, 정적 빌드는 `npm run build`다. 빌드 결과는 `dist`이며 Git에는 넣지 않는다.

## 구성

| 경로 | 역할 |
|---|---|
| `src/App.vue` | 시작 화면, 게임 화면, 설명 모달, S/N 키 |
| `src/components/StartScreen.vue` | 시작 화면 |
| `src/components/GameScreen.vue` | 상단 상태, 캔버스, 사이드바, 로그 |
| `src/components/ExplanationModal.vue` | 원본과 같은 게임 설명 |
| `src/game/constants.js` | 등급, 확률, 합성, 보스 레벨 |
| `src/game/engine.js` | 원본 스크립트의 상태와 전투 루프 |
| `src/styles/game.css` | 원본 스타일 |

화면은 브라우저 가로 전체를 쓰고, 원형 전장은 남은 칸의 비율에 맞춰 정사각형으로 커지거나 줄어든다. 세로가 더 긴 화면에서는 사이드바가 전장 아래로 내려간다. 캔버스 비트맵은 700×700이라 좌표는 그대로다. 일반 라운드에서 배속을 바꿔도 남은 적 소환은 이어진다. 합성은 클릭한 유닛과 같은 모양, 같은 등급 3마리만 합친다. 소환 유닛의 공격 간격은 게임 배속을 따른다. 유닛 강화의 현재 가격은 버튼 오른쪽 판에 나온다. 1단위는 3번마다 1원, 5단위는 매번 3원 오른다. 소환 유닛은 원형, 삼각형, 사각형이다. 종말과 뫼비우스는 원형만이다. 뫼비우스 공격은 태초, 종말과 같은 무한 스플래시다. 종말 기본 피해는 15000으로 고정이다. 종말 카드의 뇌전은 적 방어력을 없애고, 뫼비우스 카드의 파멸의 일격은 모든 적의 최대 체력 7%를 한 번만 깎는다. 원본 HTML의 뫼비우스는 일반 범위이고 종말 기본 피해는 4000이다. 오른쪽 사이드바에 유닛 판매 및 합성 칸이 있다. 고른 모양과 등급만 전부 팔거나 전부 합친다. 오른쪽 로그 아래 컬렉션은 한 판에 항목마다 한 번만 달성된다. 성령 컬렉션은 세 모양의 성령과 종말 1마리가 있어야 한다. 소환된 유닛 최대는 100마리다. 원본 HTML은 50마리다.
